## Required manual checks

1. Build the final release candidate from a clean install and serve the 1.2 golden fixture at a
   stable public HTTPS origin.
2. Submit each representative page's final rendered URL or copied managed JSON-LD to Schema.org
   Validator. Record the UTC date, validator URL, page URL, entity types, errors, warnings, and a
   screenshot or exported result location below.
3. Submit only pages whose entity type has an applicable Google rich-result feature to Google Rich
   Results Test. Record the UTC date, test URL, detected feature, errors, warnings, eligibility
   result, and evidence location below. Mark other graph types "not applicable", never "passed".
4. Confirm each page contains at most one `data-astro-aeo-graph` script, existing authored JSON-LD
   remains byte-identical, graph IDs use the stable canonical origin, and no provenance appears in
   emitted JSON-LD.
5. Confirm `/schema/graph.jsonld` and `/schema/schema-map.xml`, when enabled, are described as
   experimental Astro-AEO formats and are not submitted as Google or Schema.org discovery files.
