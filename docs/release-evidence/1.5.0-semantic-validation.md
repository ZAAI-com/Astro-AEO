## Behavior change recorded for this release

Markdown output changes on pages that use `aria-hidden` separators or tree glyphs, icons inside
definition terms, multi-image figures, or code blocks, in build companions, on-demand and SSR
Markdown, and `astro-aeo/extract`. IndexNow resubmits each page whose Markdown changed, once. The
processing cache resets once after the upgrade and logs it. The changelog lists each change.

One accepted deviation from the implementation plan: the `figure-code-window` snapshot pins the
real `index.html (what most bots see)` code window, so the snapshot runner's check for leftover
markup ignores fenced code, where quoted HTML is content rather than residue. Prose outside fences
is still checked.
