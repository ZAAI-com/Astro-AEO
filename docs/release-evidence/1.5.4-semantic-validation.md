## Semantic evidence carry-forward

The quick and final full gates rebuilt `fixtures/golden-1.2` and `fixtures/schema-tools/static`. Their complete
rendered `dist/index.html` files have the exact SHA-256 values recorded for the inputs submitted
to external validators in [1.5.3's evidence](1.5.3-semantic-validation.md). No component or schema
builder source changed. No new external validator submission was performed or is claimed.

The recorded results therefore carry forward for those byte-identical inputs: Schema.org found
zero errors and warnings in both fixtures; Google's legacy result had 3 valid items, while the
schema-tools result had 14 valid profile detections and 2 invalid merchant listings. The latter
remain intentionally incomplete authored fixtures missing images and offer currencies. These
limitations and non-critical issues remain disclosed, not recast as a clean merchant result.

The initial Node parity run exposed a second silently omitted fixture route: Astro's server
bundle cannot rewrite its prerendered `/static-page` component. The new 503 is intentional. Its
direct static companion regression was relocated to an isolated mixed-output fixture, which
now explicitly checks complete direct Markdown and failed aggregate collection. No page was
silently exempted from completeness to make a successful corpus test pass.

The first full gate passed in 334 seconds on Node 26.10.0. Since its initial candidate was
recorded, the branch gained the already-committed release-test stabilization and package-keyword
changes. Those changes were preserved, the final toolchain was recorded, and the complete gate
was rerun on the stable current candidate rather than treating the earlier pass as final evidence.

Local evidence lives in `.context/release-1.5.4/`: red/green and parity logs, installation,
Changeset inputs/status/version output, clean-archive package metadata, `quick-gate.log`,
`current-full-gate.log`, `current-benchmark.json`, and matching `current-candidate-start.json`
and `current-candidate-end.json` fingerprints.
