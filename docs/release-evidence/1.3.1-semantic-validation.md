## Behavior changes recorded for this patch

1.3.1 is a correctness release, but two changes alter output for existing projects and are
documented in `CHANGELOG.md` under `## 1.3.1`:

- `corpus.index.sections` path rules are evaluated against the locale-relative pathname on
  multilingual sites. Single-locale sites are unaffected.
- Static gzip corpus siblings pin the OS byte, so a rebuild emits different bytes than 1.3.0 for
  identical content. The artifacts are deterministic across platforms for the first time.

Neither touches JSON-LD, so neither affects the evidence above.
