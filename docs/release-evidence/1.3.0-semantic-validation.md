### Applicability checked on the validation date

- FAQ rich results were retired in May 2026, with documentation removed in June. See
  [Google's documentation updates](https://developers.google.com/search/updates).
- HowTo rich results are deprecated. See
  [Google's HowTo and FAQ announcement](https://developers.google.com/search/blog/2023/08/howto-faq-changes).
- Speakable is a limited beta for news content, not a general rich-result feature for this fixture.
  See [Google's speakable documentation](https://developers.google.com/search/docs/appearance/structured-data/speakable).
- The managed WebSite/WebPage graph produced no rich-result feature. The sitelinks search box was
  retired; do not carry forward the old record's applicability claim. See
  [Google's retirement announcement](https://developers.google.com/search/blog/2024/10/sitelinks-search-box).
