# 1.x roadmap closure ledger

2.0.0 closes the 1.x roadmap. Each row is one roadmap commitment or exit gate with one of three
dispositions:

- **shipped `<version>`**: delivered, with a pointer to the changelog section or the test that
  holds it.
- **superseded**: replaced by a different design that is shipped; the row names the replacement
  and the reason. Never used for unfinished work.
- **not shipped**: not delivered. The row says what exists instead, if anything.

The roadmap document itself is not stored in this repository. These rows are reconstructed from
the release notes, the 1.6.0 and 2.0.0 decision records and the code, and the release owner
should check them against the roadmap before tagging.

## Recorded as out of scope for 2.0.0

Plugin API v2, page-record field renames, a `migrate` command, a parser dependency, a
third-party package migration registry, a Node 24 or Astro 7 floor, and package splitting.
