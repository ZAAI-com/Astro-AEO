# 1.x roadmap closure ledger

2.0.0 closes the roadmap "Astro-AEO 1.x Implementation Plan" (2026-10-19). This ledger follows
that plan's own sections. Every row was checked against the code and tests at the 2.0.0
candidate, not against release notes alone.

Dispositions:

- **shipped `<version>`**: delivered in that real release, with a code or test pointer.
- **shipped `<version>` with reduced scope**: delivered, but narrower than the roadmap; the row
  says what is missing.
- **superseded**: replaced by a different shipped design; the row names it. Never used for
  unfinished work.
- **not shipped**: not delivered.
- Assumptions are marked **holds** or **does not hold**.

The real release numbers diverged from the roadmap's. The roadmap's 1.5.0 theme (measurement,
reports, analytics, RAG) shipped in **1.6.0**; the real 1.5.0 was a cache-integrity and EmDash
release. Several 1.3 and 1.4 items landed earlier (1.1.0, 1.2.0) or later (1.6.0) than planned.

## Explicit assumptions and defaults

| Assumption | Status | Evidence |
| --- | --- | --- |
| 1.0.0 is functionally equivalent to 0.8.0 | holds | CHANGELOG 1.0.0. |
| Static hosting guarantees `.md` files, alternate links and MIME diagnostics, not `Accept` negotiation | holds | Edge negotiation needs the explicit `astro-aeo/edge/*` handlers. |
| Runtime negotiation is `off`, `response` or `redirect`, never mandatory | holds | `markdown.negotiation` defaults to `'off'` (`src/config.js`). |
| Public artifacts stay as in 1.0; new manifests, chunks, schema endpoints and analytics are opt-in | does not hold | The new artifacts are opt-in, but `schema.autoInject` defaults to `true` since 1.2.0 and changes HTML; `fixtures/golden-1.0` sets it to `false` to keep its bytes. |
| `i18n.indexes` defaults to `auto` | holds | `src/config.js`. |
| Build validation defaults to owned-artifact correctness | holds | `validation.onBuild` defaults to `'artifacts'`. |
| `AeoHead` is explicit and metadata completion is opt-in | does not hold | `metadata.fillMissing` is opt-in, but the managed graph is injected globally by default (`schema.autoInject: true`). |
| `schema-dts` supplies vocabulary types; Astro-AEO owns graph integrity | holds | `package.json` dependency; `src/schema.js`. |
| Defuddle and MDX are optional adapters | holds | Optional peers in `package.json`. |
| IndexNow, analytics, external requests and provider mutations are off until configured | holds | `src/config.js` defaults; `fix` writes only with `--write`. |
| Standard, emerging and experimental mechanisms are labeled separately | holds | `docs/STANDARDS_AND_COMPATIBILITY.md` "Format status" (uses its own label names). |
| No fabricated content, authorship, prices, reviews or business facts | holds | `src/schema.test.js` ("without inventing facts"), `src/core/head.test.js`. |
| Releases are exit-criteria gated, not date gated | holds | `release:check`, run again by W2 on the tag. |
