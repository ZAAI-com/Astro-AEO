## Semantic evidence carry-forward

The full gate rebuilt `fixtures/golden-1.2` and `fixtures/schema-tools/static`. Their complete
rendered `dist/index.html` files have the exact SHA-256 values recorded for the inputs submitted to
external validators in [1.5.3's evidence](1.5.3-semantic-validation.md) and carried forward through
[1.6.0's](1.6.0-semantic-validation.md). Neither file contains an AEO collection marker or a client
script. No component or schema builder source changed since 1.6.0. No new external validator
submission was performed or is claimed.

The recorded results therefore carry forward for those byte-identical inputs: Schema.org found
zero errors and warnings in both fixtures; Google's legacy result had 3 valid items, while the
schema-tools result had 14 valid profile detections and 2 invalid merchant listings. The latter
remain intentionally incomplete authored fixtures missing images and offer currencies. These
limitations and non-critical issues remain disclosed, not recast as a clean merchant result.

## Benchmark baseline move

W2's project benchmark checked out `29729bb`, a commit on no branch that CI could reach only
through the since-deleted `benchmark-baseline-29729bb` tag, and the microbenchmark compared 1.6.1
against that commit's sizes. Both now use the published `1.6.0` tag (`b7d76f0`), which stays
untouched. `benchmarks/baseline-1.6.0.json` is a size-only reference recorded from a clean `1.6.0`
worktree: 494,916 packed / 1,892,681 unpacked bytes and 233 files, equal to the published 1.6.0
tarball, with every absolute ceiling passing. Its Node and Cloudflare bundle bytes are within
0.2 percent of the 1.6.0 W2 measurements on Linux. `baseline-postfix-29729bb.json`, the archived
1.6.0 reports, and the 1.6.0 evidence remain unchanged historical records.
